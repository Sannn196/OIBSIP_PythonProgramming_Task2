# BMI Calculator

Project Description
A simple command-line BMI (Body Mass Index) Calculator developed using Python. This application calculates BMI based on the user's weight and height and classifies the result into standard BMI categories.

 Features
- Accepts weight in kilograms.
- Accepts height in meters.
- Calculates BMI using the standard formula.
- Displays BMI rounded to 2 decimal places.
- Classifies BMI into four categories.
- Validates numeric inputs.
- Rejects zero and negative values.
- Handles invalid inputs with error messages.

 Technologies Used
- Python
- input() function
- Conditional Statements
- While Loop
- Exception Handling

BMI Formula
BMI = Weight (kg) / Height (m)²

 BMI Categories
- Underweight: Below 18.5
- Normal: 18.5 – 24.9
- Overweight: 25 – 29.9
- Obese: 30 and above

 How to Run
1. Download or clone this repository.
2. Open the Python file.
3. Run the program using Python IDLE or Jupyter.
4. Enter your weight in kilograms.
5. Enter your height in meters.
6. View your BMI result and category.
